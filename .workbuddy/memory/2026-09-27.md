## 澄清两个常见误解（回答用户提问，勿再猜）

- **工作区不是按 Issue 分目录**：`workspace/<仓库名>/` 一个仓库一份克隆，跨 Issue 复用，
  隔离靠**分支**（同一时刻只有一份检出的工作分支）。真机证据：`D:/opt/applications/talos/workspace/Talos`
  里同时有 `feature/req-2251`(检出) / `main` / 旧的 `req/REQ-2251`。`D:/data/talos/workspace` 是空目录（旧副本位置）。
  机械节点(git) 与 Coding Agent 节点（需求评审等）**同一个目录**，CLI 的 cwd 就是它（AgentCliRunner `pb.directory(workdir)`）。
  ⚠️ 风险：跨 Issue 共享 clone，A 的未提交改动会被 B 切分支时带走 / 或触发 `-B` 强建分支把改动带到 B 的分支。
- **节点日志没有行级时间戳**（`t_task_node.execLog` 纯文本，前端 `<pre>` 原样渲染）：
