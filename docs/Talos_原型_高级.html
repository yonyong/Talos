系统架构

反向长连接，代码不出内网

客户端主动建连，服务端只负责编排与下发；推理与产物始终留在终端一侧。

核心能力

一条流水线，覆盖研发全程

采集、判定、分拣、编排、执行、回流——每个环节都在同一条可观测的流水线上。

智能准入与分拣

基于服务端知识库自动判定 Issue 是否准入，并识别关联项目与代码仓库，命中即生成执行上下文。

端侧 Coding Agent

同一终端可挂载多后端，配置即下发，执行即回传。文档生成同样由端侧 Agent 完成——它需要真正读懂代码。

双轨工作流编排

需求与缺陷各自的标准链路可可视化编排，节点按策略自动推进，失败可恢复、可续跑。

全链路可观测

渲染后的 Prompt、每次调用的模型与费用、客户端连接与作业进度，在服务端一览无余。

没有花哨的仪表盘，只有该看见的信息：链路进度、节点状态、用量，用线条而非色块表达。
