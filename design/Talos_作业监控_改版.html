这版改了什么（对照原页面）

  1. 页头收敛：原来 4 个同款 chip（自动刷新 / 更新于 / 阻塞 / 离线）语义混杂。自动刷新 与 更新于 合为一个控件；异常改成彩色告警 pill，一切正常时整行消失。
  2. 四条等高横带 → 一张概览卡：标题、阻塞原因、操作、进度、诊断（准入 / 分拣 / 客户端）收进同一张卡，且第一句话直接说清「卡在哪、需要你做什么」。
  3. 操作按钮分级：主操作 人工通过 实心 accent；标记失败 描边；重新执行 弱化；取消实例 红字无边框。危险操作不再和主操作等权。
  4. 进度不再只有一条灰线：1/7 已完成 配分段条（完成 / 跳过 / 阻塞 / 待执行四色）+ 图例，解决「0/7 已完成但四个节点都写着已跳过」的矛盾感。
  5. 左列表能分辨了：加左侧状态色条、当前节点（卡在 4. 设计评审）、等待时长；选中态用 accent 靛蓝，不再与「阻塞」的橙色撞色。
  6. 节点区成为主体：默认时间线，一行一节点、状态 / 耗时 / 日志摘要一行读全；查看日志 → 常态隐藏、hover 才显。
  7. 拓扑图节点 116px → 168px：标题、状态、执行信息分三行不再截断；边标签从连线上移到节点上方，不再压线。
