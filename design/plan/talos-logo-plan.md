# Talos Logo 设计方案

## 定位

Talos = 研发周期全自动流程平台。名称取自希腊神话中守护克里特岛的青铜自动机，隐喻「不知疲倦的守护与编排」。

## 概念：「Gyroscope」（非字母）

刻意不做字母 T / 盾牌对勾——避免通用 SaaS 语汇。

- **软圆角方（squircle）**：现代产品图标形态
- **深靛 → 靛 → 青紫渐变**：延续 design system accent，但更沉、更克制
- **双椭圆交轨**：陀螺仪 / 天体轨道，对应研发闭环与持续编排
- **中心菱形节点**：观测核心 / 编排中枢
