# Talos Logo 设计方案

## 定稿视觉

软圆角方 + 靛→青紫渐变；白线为：
- 轨道环（半透明）
- 弧形横杠（圆润端点）
- 竖向主干
- 底部菱形节点

色调保持现有 accent 系，不做色相调整；线条加粗、圆角端点。

## 资产

| 文件 | 用途 |
|------|------|
| `web/public/favicon.svg` | 浏览器图标 |
| `web/public/brand/talos-mark.svg` | 独立标记 |
| `web/public/brand/talos-lockup.svg` | 横排 lockup |
| `web/src/icons.tsx` → `Mark` | 应用内品牌组件 |

参考图：用户确认的定稿视觉（弧形横杠 + 轨道环 + 菱形）。
